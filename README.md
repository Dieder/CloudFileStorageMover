# Cloud file mover

Main use is download multimedia files (read photos) from cloud services or local external media sources. Its also possible to upload photos to personal blob storage.
This app is build with MAUI. 

## Sources
The MAUI app is an application where you can download media files (namely photo's) from some cloud sources:
-  Google photo picker
-  P Cloud
-  Mega
-  Google Drive

Unfortunately some other cloud provides like Amazone don't expose API's. 
Also you can import photo's from external media (hard)drives and photo devices. 

## Most interesting features
- Google lauthentication
- Cloud Drive API's
- Google Photos API download photo's picker
- Upload photo's to blob storage
- Mini photo album for blob storage and downloaded Google photo's
  
This is an hobby project.
